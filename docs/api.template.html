API reference

Every public type, function and value, in the package it comes from. Straight from the interfaces and the doc comments in the source.

The facade package, moonbitstack/moonasgi, re-exports all ten of these under one name; each declaration is documented below in the package that defines it.

How this page is made

scripts/gen_api.py reads each package's pkg.generated.mbti and the /// comments beside the code, then writes this page. If a declaration changes and the page does not, the build fails.
